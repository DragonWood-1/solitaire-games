About This Sudoku Game

Sudoku is a logic puzzle played on a nine-by-nine grid that is divided into nine three-by-three boxes. Some cells arrive filled in; the rest are yours to complete. The single rule is that every row, every column and every three-by-three box must contain each of the digits one through nine exactly once. There is no arithmetic involved and no guessing required. A properly constructed puzzle has exactly one solution, and that solution can always be reached by reasoning alone.

To play here, click a cell to select it and then click a number on the pad or type a digit on your keyboard. Press Delete or Backspace, or click the same number again, to clear a cell. The given clues are fixed and cannot be overwritten. Choose Easy, Medium or Hard before starting a new game; harder settings remove more starting clues and require longer chains of deduction rather than simple scanning.

Solving Techniques That Actually Help

Scan for the last empty cell

The first pass on any puzzle should be looking for rows, columns and boxes that already have eight of their nine digits. The missing digit is forced. This sounds trivial, but each cell you fill in creates new constraints elsewhere, so a single easy placement often cascades into three or four more.

Cross-hatch one digit at a time

Pick a digit that already appears several times on the grid, say seven. For each box that still needs a seven, mentally draw lines along every row and column that already contains one. Those lines eliminate cells. If only one cell in the box survives, the seven goes there. Working digit by digit rather than cell by cell is far faster on easy and medium puzzles.

Use notes for genuine candidates only

Turn on Notes mode and the numbers you enter become small pencil marks instead of answers. The discipline that separates fast solvers from slow ones is being honest with pencil marks: write down every candidate a cell can take, not just the ones you find interesting, and erase them as soon as a placement rules them out. A stale pencil mark will send you down a false path.

Look for naked and hidden pairs

If two cells in the same row, column or box can only hold the same two digits, those two digits must occupy those two cells in some order, so you can strike them out of every other cell in that unit. This is a naked pair. The mirror image is the hidden pair: if two digits can only go in two particular cells of a unit, then those cells hold only that pair, and any other candidates you had pencilled in there can be erased. These two patterns will carry you through most hard puzzles.

Try pointing pairs when you are stuck

If, within one box, a digit's only possible cells all sit in the same row, then that digit must be in that row somewhere inside the box, which means it cannot appear in that row anywhere outside the box. The same logic works for columns. It is a small elimination but it often unlocks the position when scanning has dried up.

Features on This Grid

Puzzles are generated fresh each time rather than pulled from a fixed list, so you will not repeat a grid you have already solved. A timer runs while you work if you want to measure your progress, and it can be ignored entirely if you would rather take your time. Error highlighting can be toggled on or off: leave it on while learning so mistakes surface immediately, or switch it off for a stricter challenge where a wrong digit stays hidden until you check the board yourself.

Three assistance buttons sit under the grid. Check tells you whether what you have entered so far is consistent with the solution. Hint reveals one correct digit in the cell you have selected, which is the right tool when you are stuck on a single square rather than lost overall. Solve fills the whole grid, useful when you want to see where your reasoning went wrong. Using a hint does not end the game, so you can lean on it once and carry on solving the rest yourself.
